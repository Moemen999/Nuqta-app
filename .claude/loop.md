## كل لفّة = خطوة واحدة واضحة

0. **اقرا الأول:** `reports/2026-11-17-full-app-audit.md` (الجدول + النتايج)، وآخر 10 سطور في `TIMELINE.md`، و`git log --oneline -10`، و`git status`.
   - لو فيه تعديلات مش متكومتة: دي شغل وكيل لسه شغّال أو وقع. لو فيه وكيل منفّذ شغّال (اسأل `ListAgents`/الإشعارات)، **متبدأش كاتب تاني** — استنى. لو مفيش، راجعها: اختبارات خضرا ← كوميت؛ مش خضرا ← كمّل التصليح.
   - خد القفل: `scripts/agent-lock.sh acquire claude-code` (لو مع claude-code من لفّة قديمة كمّل).
1. **الميزة الحالية** = أول صف في الجدول مش ✅. مراحلها بالترتيب، وكل لفّة تعمل اللي عليه الدور:
   a. **مراجعة على الملفات كاملة (مش الفرق)، قراية بس، بالتوازي (5 وكلاء بالكتير):**
      - فلوس (لو الميزة فيها فلوس): `money-reviewer` + `silent-failure-hunter` — **opus**
      - نصوص: `arabic-copy-reviewer` — **sonnet**
      - وصولية: `a11y-architect` — **sonnet**
      - كود عام لو مفيش فلوس: `react-reviewer` أو `code-reviewer` — **sonnet**
      - جرد الملفات قبل المراجعة لو مش واضحة: `code-explorer` — **haiku**
      كل مراجع يبدأ تقريره بسطر «اتراجع إيه بالظبط، وإيه اللي برّه».
   b. **المشكّك** على كل HIGH/CRITICAL، أو سببين مختلفين لنفس المشكلة: وكيل قراية بس (`code-explorer` — **opus** لو فلوس، **sonnet** غير كده) يحاول يثبت إنها غلط. اللي يقع يتشال ويتكتب ليه.
   c. **التصليح:** وكيل منفّذ واحد (`general-purpose` — **opus** لو فلوس، **sonnet** غير كده)، اختبار أول لكل تصليح فلوس، وتأكيد إن الاختبار بيقع من غير التصليح. نصوص اتقرر شكلها قبل كده مع مؤمن متتغيّرش من غير ما يتسأل.
   d. **المراجعة التانية** على التصليحات: فلوس ← `money-reviewer` + `silent-failure-hunter` (جولتين بالظبط للتغيير، مفيش تالتة)؛ غير كده المراجع اللي لقى.
   e. **التحقق:** `npx tsc --noEmit`، `npm run lint`، الوحدة (`npx jest --silent --testPathIgnorePatterns '/node_modules/' '/.claude/' 'emulator'`)، ولو الميزة فيها `DataContext`: `npm run test:db`. تشغيل الاختبارات وقراية الأرقام ممكن **haiku**.
   f. **كوميت لكل مرحلة** (رسالة فيها أسامي المراجعين) + push للفرع + حدّث صف الميزة والنتايج في التقرير + سطر في `TIMELINE.md` — في نفس الكوميت.
2. لما الميزة تخلص (كل الخانات ✅): الصف ✅ وكمّل الميزة اللي بعدها في اللفّة الجاية.
3. **التحقق النهائي** (بعد الـ12): `npm test` + `npm run test:db` + `timeline-auditor` (**sonnet**) + تقرير ختامي في نفس الملف (اللي اتصلح، واللي اتساب وليه، والأسئلة لمؤمن) + بناء preview واحد. وبعدين خط النهاية (فوق).
